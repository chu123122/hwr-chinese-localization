# 人头落地：重铸 中文汉化补丁（HWR Chinese Localization）

《Heads Will Roll: Reforged》（Steam 版 2.99e，Ren'Py 7.4.10）的完整简体中文汉化。

全量 **20,852 条**译文（主线 + 全部 DLC 对话、物品、UI、教程），基于游戏原文独立翻译，
非官方中文翻译的复制品（官方机翻存在大量缺陷：丢失道具效果描述、插值损坏崩溃等，本补丁全部修复）。
主要使用deepseek flash 0731 模型翻译 + Gemini3.1pro 精修+ gpt 5.6 sol 审查
## 安装（解压即用）

1. 下载 `HWR_Chinese_Localization_vX.Y.Z.zip`
2. **解压到游戏根目录**（即 `steamapps\common\Heads Will Roll Reforged\` 下，zip 内含 `game\tl\chinese\` 结构，自动落到正确位置）
3. 启动游戏 → 语言选择器选 **中文**

首次启动会自动编译翻译文件，无需其他操作。

## 卸载

Steam 客户端 → 右键游戏 → 属性 → 已安装文件 → **验证游戏文件完整性**
（会还原官方中文；也可先备份原 `game\tl\chinese\` 目录再安装，备份还原更快）。

## 兼容性

- 适配 Steam 官方版 **2.99e**（Ren'Py 7.4.10）
- 游戏更新后翻译可能失效，等待补丁更新
- 安装后请勿运行"验证游戏文件完整性"（会移除本汉化，重新解压即可恢复）

## 已知限制

- 游戏配音为英/俄语原声，汉化为中文字幕
- 文本使用游戏自带中文字体，无需额外安装
